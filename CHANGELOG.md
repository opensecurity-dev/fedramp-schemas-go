## [v0.1.0] - 2026-11-05

### Highlights

- Go types for the FedRAMP 2026-06-24 machine-readable schema set (JSON Schema draft 2020-12)
- Authoritative JSON Schemas embedded for offline runtime validation
- Generated MkDocs documentation site published to GitHub Pages

### Added

- Common Definitions types shared across schemas (VulnerabilityDetail, Detection, NRating, AcceptedVulnerabilityInfo, ReportPeriodDate/DateTime)
- CertificationPackageOverview document type (FRC-CSO-PKG)
- SecurityDecisionRecord document type (SDR-CSO-FRR)
- SignificantChangeNotification document type (SCN-CSO-INF)
- IncidentReport document type (IEC-CSO-IIR / OIR / FIR)
- OngoingCertificationReport document type (CCM-OCR-AVL)
- VulnerabilityDetailReport document type (VER-RPT-VDT)
- AcceptedVulnerabilityInfoReport document type (VER-RPT-AVI)
- HistoricalVERActivity document type (VER-TFR-MRH)
- AdvisorInformation and AssessorInformation document types (MKT-CAS-WEB, MKT-IAS-WEB)
- Embedded JSON Schemas with SchemaBytes, SchemaMeta, Schemas, and SchemaFS accessors
- Runtime validation via Validator, ValidateBytes, and ValidateValue, resolving cross-file $refs against embedded schemas
- IsValid and Values helpers for every enumerated type

### Documentation

- MkDocs Material site with home, Go usage guide, and per-schema reference pages generated from the schemas
- Runnable godoc examples for marshalling, unmarshalling, validation, and schema listing
- README with usage, conventions, and repository layout

### Build

- CI workflow running gofmt, go vet, race tests, golangci-lint, CodeQL, and a generated-docs freshness check
- GitHub Pages deploy workflow building the MkDocs site
- gen/docs.go generator producing the schema reference and download pages
