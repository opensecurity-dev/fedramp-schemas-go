# Schema Reference

Reference documentation generated from the FedRAMP JSON Schema files vendored in this repository. The authoritative JSON Schema documents are available for download from each page.

| Schema | Version | Description |
|---|---|---|
| [FedRAMP Accepted Vulnerability Info (VER-RPT-AVI)](accepted-vulnerability-info.md) | `0.1.1` | Accepted vulnerability information required when reporting vulnerability detection and response activity per VER-RPT-AVI. |
| [FedRAMP Advisor Information (MKT-CAS-WEB)](advisor-information.md) | `1.0.1` | Public information an Advisory Service must supply in machine-readable format on their website per MKT-CAS-WEB. |
| [FedRAMP Assessor Information (MKT-IAS-WEB)](assessor-information.md) | `1.0.1` | Public information an Independent Assessment Service must supply in machine-readable format on their website per MKT-IAS-WEB. |
| [FedRAMP Certification Package Overview (FRC-CSO-PKG)](certification-package-overview.md) | `0.1.4` | Identification, service properties, contacts, and supporting documentation for a Cloud Service Offering per FRC-CSO-PKG. |
| [FedRAMP Common Definitions](common-definitions.md) | `0.3.0` | Shared type definitions referenced by other FedRAMP schemas. |
| [FedRAMP Historical Vulnerability Evaluation and Reporting Activity (VER-TFR-MRH)](historical-ver-activity.md) | `0.1.1` | Machine-readable historical Vulnerability Evaluation and Reporting activity for automated retrieval per VER-TFR-MRH. |
| [FedRAMP Incident Report (IEC-CSO-IIR / IEC-CSO-OIR / IEC-CSO-FIR)](incident-report.md) | `0.2.0` | Unified schema for the three incident report types in the IEC-CSO lifecycle: Initial (IEC-CSO-IIR), Ongoing (IEC-CSO-OIR), and Final (IEC-CSO-FIR). |
| [FedRAMP Ongoing Certification Report (CCM-OCR-AVL)](ongoing-certification-report.md) | `0.2.0` | Quarterly Ongoing Certification Report (OCR) per CCM-OCR-AVL, covering the entire period since the previous report. |
| [FedRAMP Security Decision Record (SDR-CSO-FRR)](security-decision-record.md) | `1.1.1` | JSON Schema for Cloud Service Provider (CSP) system submission for FedRAMP certification per SDR-CSO-FRR. |
| [FedRAMP Significant Change Notification (SCN-CSO-INF)](significant-change-notifications.md) | `0.1.2` | Required information for a Significant Change Notification per SCN-CSO-INF. Note per the rule: structure of the information may vary depending on how the provider tracks this internally. |
| [FedRAMP Vulnerability Detail Report (VER-RPT-VDT)](vulnerability-detail-report.md) | `0.1.1` | Vulnerability detection and response activity report per VER-RPT-VDT. Covers non-accepted vulnerabilities only; see VER-RPT-AVI for accepted vulnerabilities. |
