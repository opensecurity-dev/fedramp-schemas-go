# Release Notes - v0.1.0

**Release date:** 2026-11-05

## Overview

First release of `fedramp-schemas-go`: Go types and embedded JSON Schemas for the
[FedRAMP machine-readable schema set](https://www.fedramp.gov/schemas/), schema set `2026-06-24`
(JSON Schema draft 2020-12). Applications can read, write and validate FedRAMP documents offline.

## Highlights

- Go types for every document in the FedRAMP `2026-06-24` schema set
- The JSON Schemas are embedded, so documents validate at runtime without a network call
- A documentation site with a reference page per schema, at
  [opensecurity-dev.github.io/fedramp-schemas-go](https://opensecurity-dev.github.io/fedramp-schemas-go/)

## Installation

```bash
go get github.com/opensecurity-dev/fedramp-schemas-go@v0.1.0
```

```go
import fedramp "github.com/opensecurity-dev/fedramp-schemas-go"
```

Go 1.27 or later is required.

## Added

### Document types

| Document | Go type | FedRAMP requirement |
|---|---|---|
| Certification Package Overview | `CertificationPackageOverview` | FRC-CSO-PKG |
| Security Decision Record | `SecurityDecisionRecord` | SDR-CSO-FRR |
| Significant Change Notification | `SignificantChangeNotification` | SCN-CSO-INF |
| Incident Report | `IncidentReport` | IEC-CSO-IIR / OIR / FIR |
| Ongoing Certification Report | `OngoingCertificationReport` | CCM-OCR-AVL |
| Vulnerability Detail Report | `VulnerabilityDetailReport` | VER-RPT-VDT |
| Accepted Vulnerability Info | `AcceptedVulnerabilityInfoReport` | VER-RPT-AVI |
| Historical VER Activity | `HistoricalVERActivity` | VER-TFR-MRH |
| Advisor Information | `AdvisorInformation` | MKT-CAS-WEB |
| Assessor Information | `AssessorInformation` | MKT-IAS-WEB |

The Common Definitions shared across schemas are Go types too, including `VulnerabilityDetail`, `Detection`,
`NRating`, `AcceptedVulnerabilityInfo`, `ReportPeriodDate` and `ReportPeriodDateTime`.

Every enumerated type has exported constants and `IsValid` and `Values` helpers:

```go
fedramp.CertificationType20x.IsValid() // true
fedramp.DeploymentModel("").Values()   // all permitted values
```

### Embedded schemas

- `SchemaBytes`, `SchemaMeta`, `Schemas` and `SchemaFS` give access to the vendored schema files and their
  metadata

### Validation

Validation checks a document against its embedded schema, including conditional rules the Go types can't express,
such as a final incident report requiring `resolvedAt`. Cross-file `$ref`s resolve against the embedded schemas.

- `Validate(doc)` and `MarshalValidated(doc)` for values implementing `Document`
- `ValidateBytes(schemaFile, data)` for raw JSON
- `ValidateValue(schemaFile, v)` for any value
- `NewValidator` for reusing compiled schemas

```go
err := fedramp.ValidateBytes(fedramp.SchemaFileIncidentReport, data)
```

### Conventions

- Dates and date-times are `string` values (`YYYY-MM-DD` or RFC 3339), so both formats round-trip exactly
- Optional booleans and enumerated integers are pointers, so an absent value differs from a zero value

## Documentation

- MkDocs site with a home page, a Go usage guide, a generated reference page per schema and schema downloads
- Runnable godoc examples for marshalling, unmarshalling, validation and listing schemas

## Build

- `gen/docs.go` generates the schema reference and download pages from the embedded schemas
- CI runs gofmt, `go vet`, race-enabled tests, a check that the generated docs are current, golangci-lint and
  CodeQL, and deploys the docs site to GitHub Pages
